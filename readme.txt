To repeat the Newick pairing pipeline you will need to follow the commands in match_tree_pairs.sh,
using the files provided in data.tar.xz and elsewhere, and the Perl scripts, and meeting other requirements.

To repeat only the statistical analysis you will need to follow the commands in linear_model.R,
using the table integrated_result.tsv, and have the required R libraries installed.

A complete video walkthrough is available here: https://youtu.be/EU47eD4hDlA

Citation: Chesters D, Mapping Emergence of the Insect Tree of Life, in submission.
